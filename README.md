# RaptorGRC known issues

The public list of known bugs and issues in [RaptorGRC](https://raptorgrc.com), the self-hosted,
offline GRC platform, and where each one stands.

**This repository contains no source code.** It exists so customers and evaluators can see the
problems we know about, whether they affect them, any workaround, and which release fixes them.

## How this list works

- **We publish issues here; the public doesn't post them.** Reports come to us privately, we
  investigate, and the ones that affect other users are written up here with any workaround.
- **Each issue says which versions it affects** and is closed with the release that fixes it.
- **Conversations are locked** so each issue stays a clear, accurate record.

## Found a problem?

- **Customers:** report it privately from the [portal's Feedback page](https://raptorgrc.com/portal/feedback).
- **Everyone else:** [contact us](https://raptorgrc.com/contact).
- **Security vulnerabilities:** never publicly. Use our
  [vulnerability disclosure policy](https://raptorgrc.com/vulnerability-disclosure) or email
  security@raptorgrc.com. Vulnerabilities are disclosed through that process, not on this list.

## Labels

| Label | Meaning |
|---|---|
| `bug` | Something doesn't work as it should |
| `install` | Downloading, verifying, loading or running the container |
| `documentation` | A guide or instruction is wrong or unclear |
| `confirmed` | Reproduced; not yet being fixed |
| `in-progress` | Being fixed |
| `workaround-available` | The issue describes a way around it |
| `fixed-next-release` | Fixed; ships in the next release |

Fixes are also listed in each release's notes on the portal's Downloads page.
